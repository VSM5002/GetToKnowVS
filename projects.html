02 / IoT SECURITY

SafeHaven – IoT Home Security

Developed an IoT-based home security system combining access control and intrusion detection. Used ESP32 with RFID and keypad authentication, along with sensors to detect forceful entry.

Created honeypots using fake RFID cards, keypad passwords and a fake Wi-Fi access point to identify suspicious activity. Integrated Blynk for remote security alerts.
